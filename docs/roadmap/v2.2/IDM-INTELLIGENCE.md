# IDM Intelligence — Cloud Agent

This module extends the existing IDM Mobile application with photo-based repair analysis, instrument recognition, archive matching and historical intelligence.

Core rule: AI output is always a proposal. Human confirmation is mandatory before authoritative data is stored or workflow state is changed.

Primary flow:

Photo → recognition → visible defect analysis → archive matching → confidence/evidence → manual correction/confirmation → IDM database.

AI must not autonomously determine safety, Ausmusterung, Vorkommnis closure, repair approval, master-data changes or workflow status.
